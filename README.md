# 濮院卧室 · 空间推演

3800 × 5500 mm 卧室及入口 2000 mm 衣帽区的 A/B 两版交互概念模型。

- A：中置背柜，双侧通行。
- B：长排背柜，侧向梳妆。
- 支持旋转缩放、尺寸与正交比例尺、柜门开合、柜体剖切、爆炸拆解、材质切换、墙体与吊顶控制、窗帘开合。
- 按手机竖屏适配；不展示灯具、开灯效果或视频。

图纸未明确的窗立面与家具高度为概念推演，详情见网页“尺寸依据与模型说明”。本模型不是施工图。

## 本地预览

在本目录启动任意静态 HTTP 服务，例如 `python3 -m http.server 5198`，然后打开对应地址。
