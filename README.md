# 濮院卧室 · 方案 B

独立静态 Three.js 模型：3800 × 5500 mm；1800 × 2000 床垫。

- 入口衣帽区 2500 = 450 端墙家具 + 1400 主过道 + 600 主柜 + 50 柜背。
- 主衣柜2900×600×2400；次净衣700×450×2100；抽屉柜900×450×850。
- L形桌外包1300×1100×750，两边台深450；桌下柜450×500×720。
- 左侧通道900；右侧梳妆局部750；床尾至窗帘750。
- 家具编号尺寸图、全部尺寸表、旋转、开门、剖切、爆炸拆解、材质与窗帘控制。
- 不展示灯具或开灯效果。方案A已移除。无视频，无外部CDN。

概念尺寸，非施工图。1400主通道按柜门和抽屉关闭计算。
